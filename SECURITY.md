## Supported Versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within SideGate, please do not file a public GitHub issue.

Instead, please send an encrypted or direct email to `shahriarseam17@gmail.com` with:
1. Detailed description of the vulnerability.
2. Steps to reproduce or proof-of-concept script.
3. Potential impact on agent execution sandboxes.

The maintainers will acknowledge receipt within 48 hours and coordinate remediation before public disclosure.
